# Телефон: руководство учителя

Откройте редактор и начните с демонстрационной игры: два героя, шесть заданий, все пять форматов. Изменения автоматически сохраняются в этом браузере. Для переноса на другой компьютер скачивайте проект.

## Создание игры

1. **Дизайн** — выберите смартфон, ретро или учебный телефон. Укажите ширину 280–600 px, цвета, фон, шрифт и размеры текста. Изменения сразу появляются справа.
2. **Герои** — добавьте персонажей, имена, приветствия и аватары. Обрезка аватара настраивается масштабом и положением. Героя можно отключить, дублировать, удалить или переместить.
3. **Задания** — выберите героя. Добавьте вопрос и тип ответа. Для вариантов отметьте правильные ответы; для текста перечислите допустимые ответы по одному на строку; для сортировки расставьте элементы в правильном порядке. В игре порядок перемешается. Аудиозадание принимает MP3 или WAV.
4. **Игра** — задайте жизни, значок и режим ошибок. По умолчанию неверный ответ завершает задание. В режиме повторов ученик должен изменить ответ, чтобы отправить его снова.
5. **Языки** — выберите язык служебных надписей и разрешённые клавиатуры. Авторские тексты не переводятся. Пустая пользовательская подпись означает стандартный перевод.
6. **Экраны** — настройте приветствие и три результата: без ошибок, с ошибками, поражение. Цвет результата настраивается отдельно.
7. **Звуки** — используйте встроенные сигналы или загрузите свои. Ученик может выключить звук.

## Проверка

Кнопки под телефоном открывают нужный экран без прохождения. «Показать задание» открывает выбранный вопрос. «Тест» начинает игру с нуля; ↻ запускает её заново. «Вписать» меняет только масштаб предпросмотра, а не сохранённый размер телефона. На узком экране переключайтесь между настройками и предпросмотром.

Для сортировки доступны перетаскивание, кнопки ↑/↓ и Alt+↑/↓ на выделенном элементе. В текстовом задании Enter отправляет ответ. Виртуальная клавиатура вставляет текст у курсора; системная клавиатура включается отдельной кнопкой.

История хранит 120 операций. Ctrl/Cmd+Z — отмена, Ctrl/Cmd+Shift+Z — повтор. Серия ввода в одном поле считается одной операцией до выхода из поля или другого действия.

## Сохранение и выдача ученикам

- **Сохранить проект** — редактируемый ZIP `.phonegame`, включая изображения и аудио. Можно сохранять незавершённые проекты.
- **Загрузить проект** — проверяет архив, схему и декодирование ресурсов до замены работы. Если есть изменения, редактор предлагает скачать текущий проект.
- **Скачать HTML** — один автономный файл для учеников. Работает без интернета, сервера и установки. Правильные ответы доступны в исходном коде: это учебная игра, не защищённый экзамен.
- **Облегчить код** — отдельная экспортная копия. Показывает размеры, удаляет неиспользуемые ресурсы, объединяет одинаковые файлы, уменьшает изображения. Сжатие WebP с потерями включается явно; аудио не перекодируется.
- **Код для Genially** — iframe по HTTPS-адресу уже опубликованной игры. См. [инструкцию](genially.md).

Игра не записывает голос, не обращается к контактам телефона и не отправляет оценки. После перезагрузки прогресс ученика сбрасывается. Редактор не передаёт содержимое проекта на сервер.

Ограничения файлов: аватар/изображение задания — 5 МБ; фон — 10 МБ; аудио — 20 МБ; файл проекта — 100 МБ. При ошибке браузерного хранилища скачайте проект.
