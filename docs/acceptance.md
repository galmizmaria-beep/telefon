## Что ещё требуется для полной приёмки ТЗ

- Испытания в актуальной и предыдущей версиях Edge, Firefox, Safari; Safari iOS и Chrome Android на устройствах.
- Проверка озвучивания скринридером, тач-перетаскивания и системных мобильных клавиатур. Для перестановки есть кнопочная альтернатива.
- Контроль задержек на 4 ядрах / 8 ГБ с реальным набором изображений и аудио 20 МБ; текущая нагрузка использует синтетически размноженный встроенный WAV.
- Прогон опубликованной игры в целевом Genially, включая политику iframe и воспроизведение звука после жеста пользователя.

## Реализационные замечания

ZIP записывается без сжатия; файлы PNG/JPEG/MP3 обычно уже сжаты. Облегчение JS использует консервативное удаление отступов и отдельных комментариев, а не агрессивное переименование переменных. CSS уплотняется, медиа очищаются/дедуплицируются, изображения могут уменьшаться. Если файл не становится меньше, это явно показывается.

Web Worker используется на localhost/HTTPS. Резервная обработка при недоступности Worker может занимать главный поток; большие проекты следует открывать через рекомендуемый сервер. Экспорт ученика не зависит от Worker или сервера.

## Зафиксированный замер производительности

- 30 героев, 300 заданий, 19,88 МиБ встроенных WAV-ресурсов.
- 600 обновлений за приблизительно 60 секунд.
- P95 времени обновления до следующего animation frame: **15,3 мс**; максимум: **17,0 мс**.
- Long Task (>50 мс): **0**.
- Исходное поле ввода, 600 введённых символов, фокус и курсор сохранены.
- Замер относится к игровому предпросмотру на описанной машине; это не доказательство всей матрицы производительности на контрольном ноутбуке из ТЗ.
