# Встраивание в Genially

1. В редакторе нажмите **Скачать HTML**.
2. Переименуйте файл, например в `game.html`, и загрузите его в репозиторий/каталог, публикуемый по HTTPS. Для этого проекта можно положить файл в `examples/`: workflow GitHub Pages публикует этот каталог.
3. Откройте адрес игры непосредственно в браузере. При репозитории `telefon` это может быть `https://USERNAME.github.io/telefon/examples/game.html`.
4. В редакторе Телефон откройте **Код для Genially**, укажите реальный адрес и размеры.
5. Скопируйте iframe в инструмент вставки внешнего содержимого Genially. Название раздела зависит от интерфейса и языка аккаунта.
6. Опубликуйте материал и проверьте игру на опубликованной странице, затем на смартфоне.

Пример (замените USERNAME и адрес на свои):

```html
<iframe src="https://USERNAME.github.io/telefon/examples/game.html"
  width="400" height="720" style="border:0;max-width:100%"
  title="Телефон знаний" allow="autoplay; fullscreen" allowfullscreen></iframe>
```

Проверяйте звонок после клика, аудио, пять видов ответа, смену раскладки, прокрутку и все результаты. Хостинг должен разрешать iframe: ограничения CSP `frame-ancestors` и `X-Frame-Options` могут блокировать игру.

Локальные пути, `file://`, `blob:` и HTTP не принимаются. Поддержка HTTPS для внешнего содержимого подтверждается [официальной справкой Genially](https://help.genially.com/pt_br/no-consigo-ver-o-site-ou-aplicativo-que-eu-inseri-em-genially-BkBX5wHno). Генератор ничего не публикует. Передача оценок обратно в Genially и srcdoc не реализованы.

**Статус приёмки:** код iframe проверен локально; испытание на целевом опубликованном материале Genially не выполнено, поскольку аккаунт и адрес материала не предоставлены. Работа на конкретном тарифе и ограничения целевого аккаунта не подтверждены.
