# Формат встраивания

«Код для Genially» формирует iframe именно текущего проекта. Для обычной вставки адрес отдельно опубликованного HTML не требуется. «Облегчить код» сжимает медиа экспортной копии и данные Gzip; обе кнопки приводят к одному окну с копированием и проверкой iframe.

Игровые данные передаются в fragment части HTTPS-ссылки `player.html#pg2j.…` (JSON/base64url) или `player.html#pg2z.…` (Gzip/base64url). Fragment не отправляется серверу GitHub при HTTP-запросе. Содержимое доступно любому, кто получил полный код или ссылку. Игровые результаты не передаются на сервер.

Проигрыватель берёт движок, шрифты и KaTeX с сайта редактора; содержимое и медиа берёт из fragment. Поэтому для игры внутри Genially нужен интернет, но отдельная публикация каждой игры не нужна. Изменение проекта требует повторно скопировать код.

Лимит ссылки в редакторе — 1 500 000 символов; лимит распакованных данных — 100 МБ. Ограничения поля вставки Genially могут быть строже: для больших медиа используйте облегчение или необязательный HTTPS-адрес опубликованного автономного HTML. Код не обрезается молча.

Стандартный HTTPS iframe выбран по документации внешнего содержимого Genially: https://help.genially.com/pt_br/no-consigo-ver-o-site-ou-aplicativo-que-eu-inseri-em-genially-BkBX5wHno. Проверка во встроенном окне редактора проверяет тот же проигрыватель и данные; она не заменяет испытание на целевом аккаунте Genially.

Автономный HTML остаётся отдельным способом выдачи игры и полностью работает без интернета. MathML поддерживается актуальными Chrome, Firefox и Safari.

Размер слайда задаётся в окне кода (по умолчанию 1200 × 675). В Genially растяните вставленный блок на весь слайд: код внутри iframe не может изменять размер родительского слайда. Фон заполняет весь блок, телефон пропорционально вписывается по обеим осям. Внешняя прокрутка отключена; длинный вопрос можно прокручивать внутри экрана телефона. Клавиатура открывается только по кнопке ⌨ и не дублирует панель ответа.
