# Телефон · конструктор учебных игр

Статический браузерный редактор по ТЗ «Редактор игры Телефон». Русский интерфейс, живой предпросмотр, пять типов заданий, три шаблона телефона, девять языков, десять раскладок, ZIP-проекты и автономный HTML.

## Запуск

В каталоге проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте **http://localhost:8000**. Установка npm-пакетов, база данных и серверная часть не нужны. Python используется только как локальный сервер. Готовый экспорт игры открывается двойным щелчком без сервера. Для редактора используйте localhost или HTTPS, чтобы работали Web Worker, IndexedDB и буфер обмена.

## Загрузка на GitHub

1. Создайте репозиторий на GitHub.
2. Загрузите содержимое этой папки, включая `src`, `assets`, `examples`, `docs`, `scripts`, `tests` и `.github/workflows/pages.yml`. Файл исходного ТЗ необязателен.
3. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
4. Запустите workflow **Check and deploy editor** либо отправьте изменения в ветку `main`.
5. Адрес редактора появится в результате workflow: `https://USERNAME.github.io/REPOSITORY/`.

Настройка workflow соответствует [официальной документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

Workflow тестирует движок, пересобирает экспорт, генерирует примеры и публикует только публичные файлы. Учётные данные или токены в проекте отсутствуют. Репозиторий проекта: https://github.com/galmizmaria-beep/telefon. Для запуска сайта включите GitHub Pages согласно шагам выше.

Альтернатива: выберите Pages → Deploy from a branch → `main` → `/ (root)`; готовые файлы уже включены в поставку. При таком способе публикуется всё содержимое ветки, в том числе документация и исходное ТЗ, если вы его загрузили.

## Что входит

- Редактор и единый игровой движок для предпросмотра и HTML.
- Герои, аватары с обрезкой, задания, история на 120 операций.
- Один ответ, множественный выбор, текст, сортировка, аудио.
- Точная проверка по ID; Unicode NFC и языковая нормализация текста.
- Жизни, повторы, баллы, три итоговых экрана, отключение звука.
- IndexedDB-черновик, ZIP `.phonegame`, импорт с проверками целостности.
- Автономный HTML со шрифтами и медиа, оптимизация копии, iframe для Genially.
- Демонстрационная игра: [проект](examples/demo.phonegame), [HTML](examples/game.html), [облегчённый HTML](examples/game.light.html).

## Разработка и проверки

Node.js 20+ нужен только для автоматических тестов и генерации примеров. Зависимостей npm нет.

```sh
npm test
python3 scripts/build.py
node scripts/examples.cjs
```

После изменения `src/model.js`, `src/i18n.js`, `src/game.js` или `src/game.css` обязательно пересоберите `src/export-sources.js`: редактор использует этот пакет для полностью автономного экспорта. Не редактируйте пакет вручную.

Для дополнительной UI-проверки: запустите отдельный headless Chrome с `--remote-debugging-port=9228` и временным `--user-data-dir`, запустите локальный сервер, затем `node scripts/browser-check.cjs`. Тест использует только отдельный тестовый браузер, создаёт скриншоты в `.tmp` и проверяет offline `file://`.

Архитектура: `model.js` — данные, схема, проверка, сессия; `i18n.js` — переводы; `game.js` — игровой интерфейс с сохранением DOM-узлов; `archive.js` — ZIP и HTML; `worker.js` — тяжёлые операции; `editor.js` — редактор и черновик; `build.py` — пакет экспортируемого движка и шрифтов.
