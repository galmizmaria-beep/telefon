# Телефон · редактор учебных игр

[Открыть редактор](https://galmizmaria-beep.github.io/telefon/) · [Скачать комплект](https://github.com/galmizmaria-beep/telefon/raw/refs/heads/main/telefon-github.zip)

Версия 1.2: автономный HTML и готовый код текущей игры для Genially, картинки и анимированные GIF, автоматическое сжатие изображений, LaTeX и единый язык игры.

## Запуск и сборка

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть http://localhost:8000. Установка npm-пакетов и серверная база данных не нужны.

Для разработчика (Node.js 20+ и Python 3):

```sh
npm test
python3 scripts/build.py
node scripts/examples.cjs
```

После изменения игрового движка пересоберите `src/export-sources.js`: это пакет для автономного HTML. Все библиотеки, шрифты и обработчик GIF находятся в репозитории.

## Возможности

- Пять типов заданий, герои, три шаблона телефона, жизни, звуки, история изменений.
- Игра вписывается в ширину и высоту слайда без внешней прокрутки. В коде Genially указывается размер слайда (по умолчанию 1200 × 675), вставленный блок нужно растянуть на весь слайд.
- Клавиатура скрыта до нажатия ⌨. Одна панель ответа; фиксированные ряды букв, цифры в верхнем ряду и отдельная цифровая раскладка 3 × 4.
- Единый язык служебных надписей, проверки текста и буквенной клавиатуры. Отдельно доступны цифры и математические символы; для выбора ответа используются буквенные кнопки.
- LaTeX в вопросах, вариантах и пояснениях: `$...$` и `$$...$$`. Рендеринг через локальный KaTeX в MathML. Ответы сравниваются с заданными учителем значениями; это не система символьного решения уравнений.
- Картинки и GIF в аватарах, заданиях, фоне сцены/экрана и итоговых экранах. При загрузке изображения автоматически уменьшаются и сжимаются. GIF сохраняют кадры, задержки и повторение; если оптимизация увеличивает размер, сохраняется меньший исходный файл.
- `.phonegame`: ZIP со всеми ресурсами. Версия схемы 2; проекты версии 1 преобразуются при загрузке.
- **Скачать HTML**: один автономный файл, работает через file:// без интернета, включая формулы, шрифты и медиа.
- **Код для Genially**: готовый iframe текущей игры без обязательного ввода адреса HTML. Данные хранятся в ссылке iframe, а движок загружается из `player.html` на GitHub Pages. Для iframe нужен интернет.
- **Облегчить код**: оптимизирует копию медиа и сжимает данные игры Gzip; уменьшенный код можно сразу скопировать. Исходный проект не изменяется. Обычный и облегчённый HTML также доступны.

Копирование поддерживает запасной путь для браузеров, где Clipboard API недоступен. Если браузер запрещает оба способа, код выделяется для ручного копирования.

## Размещение

Исходники: https://github.com/galmizmaria-beep/telefon. GitHub Actions проверяет тесты, собирает примеры и публикует `index.html`, `player.html`, `src`, `assets`, `vendor`, `docs`, `examples` через GitHub Pages.

Если переносите редактор в другой репозиторий, публикуйте весь комплект, включая `player.html` и `vendor`. Адрес проигрывателя для Genially определяется автоматически по адресу редактора. Локальная версия использует опубликованный проигрыватель этого репозитория.

Примеры: [проект](examples/demo.phonegame), [HTML](examples/game.html), [облегчённый HTML](examples/game.light.html).
